# jojo

แอพมือถือของร้าน เปิดผ่านโปรแกรม **อะตอมมิค** บนคอม (Wi-Fi เดียวกัน)

- ค้น/สแกนสินค้า (SKU / GTIN / ชื่อ) จากข้อมูล SKU Merchant ที่อะตอมมิคโหลดจาก BigSeller
- ดูกล้อง CCTV สด + คลิปย้อนหลัง (กล้องเครื่องนี้ + กล้องเครื่องอื่นที่บันทึกในหน้า กล้อง CCTV)

## โครงสร้าง

- `app/` หน้าแอพมือถือ (HTML/CSS/JS ล้วน ไม่ต้อง build) — อะตอมมิคเสิร์ฟให้ที่พอร์ต 5540
  - `vendor/zxing.min.js` ตัวอ่านบาร์โค้ด (@zxing/library 0.21.3, Apache-2.0)
- `assets/jojo.webp` รูปต้นฉบับ (ไอคอน)
- ฝั่งคอม: `อะตอมมิค\โปรแกรม\jojo.js` (ตัวกลาง: รหัสจับคู่, API สินค้า, ส่งต่อภาพกล้อง) และ `shell\jojo.js` (หน้าตั้งค่า)

## แก้แอพ

แก้ไฟล์ใน `app/` แล้ว build อะตอมมิคใหม่ (`npx electron-builder --win nsis` ในโฟลเดอร์ `อะตอมมิค\โปรแกรม`) — ไฟล์ใน `app/` ถูกรวมไปกับตัวติดตั้งอะตอมมิค

ตอนพัฒนา: รันอะตอมมิคแบบ dev (`npm start`) จะเสิร์ฟ `app/` ตรงจากโฟลเดอร์นี้ แก้แล้วรีเฟรชมือถือได้เลย
