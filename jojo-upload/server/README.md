# jojo server (ตัวทดลอง แบบ B)

แอพ jojo ตัวใหม่: แต่ละคนล็อกอินด้วย **บัญชีย่อย BigSeller ของตัวเอง** ไม่ต้องพึ่งอะตอมมิค/คอมในร้าน
เซิร์ฟเวอร์ (Node.js) เปิดเบราว์เซอร์ซ่อน (Edge ในเครื่อง ผ่าน playwright-core) แล้วเรียกหลังบ้าน BigSeller แทนแต่ละคน
**ข้อมูลทุกอย่างอยู่ใน BigSeller** (เจ้าของสั่ง — ไม่มีฐานข้อมูลแยก) ตำแหน่ง C- / K- / H- = ชั้นวาง (Shelf) ใน BigSeller

## รัน
```
npm install
npm start        # BigSeller จริง → http://127.0.0.1:5600 (เปิดได้จากคอมเครื่องนี้)
npm run mock     # ข้อมูลจำลอง ไม่แตะ BigSeller (รหัสยืนยันในโหมดนี้คือ A7K2, เลขพัสดุทดสอบ TEST001)
```
- **มือถือในวง Wi-Fi:** ตั้ง `JOJO_LAN=1` → https ที่พอร์ต `JOJO_PORT + 3` (เช่น `https://192.168.1.19:5604`)
  - ใบรับรองทำเองครั้งแรก (`cert.pfx`) — มือถือเตือนครั้งแรก กด ขั้นสูง → ไปต่อ
  - Windows อาจถามให้อนุญาต Node.js ผ่านไฟร์วอลล์ (เครือข่ายส่วนตัว)
  - ต้องเป็น https มือถือถึงเปิดกล้องสแกนได้
- **บันทึกลง BigSeller จริง** (ปุ่มยืนยันล็อกออเดอร์ = `scanVerifySuccess`): **ปิดไว้** ต้องตั้ง `JOJO_WRITE=1` และเจ้าของต้องสั่งก่อนลองกับออเดอร์จริง
- ตั้งค่าอื่น: `JOJO_PORT` (5600) · `JOJO_HOST` (127.0.0.1) · `JOJO_BROWSER` (`msedge` บน Windows, `chromium` บนเซิร์ฟเวอร์ Linux)

## ไฟล์
- `server.js` — ทุกอย่างฝั่งเซิร์ฟเวอร์ (ล็อกอิน, ค้นสต็อก, ล็อกออเดอร์, สำรวจหน้า BigSeller)
- `public/index.html` — แอพมือถือทั้งหมด (หน้าเดียว เปลี่ยนหน้าด้วย `#home`, `#lock`, `#stock` …) · `public/vendor/zxing.min.js` ตัวอ่านบาร์โค้ด
- ไฟล์ที่เซิร์ฟเวอร์สร้างเอง (ไม่ต้องส่งต่อ): `debug-*.json/png` (ข้อมูลดิบไว้ปรับชื่อช่อง), `lock-log.jsonl` (ใครล็อกอะไร), `cert.pfx`
- ดีไซน์: `../design/jojo-manga-ui.html` (ธีมม่วง–เหลือง JoJo, ครบ 10 หน้า)

## สิ่งที่เจ้าของตอบไว้แล้ว (ใช้ทำหน้าที่เหลือ)
- **2 ของค้าง:** = หน้า "ออเดอร์ค้าง" ของอะตอมมิค (Google Sheet `../../อะตอมมิค/โปรแกรม/sheets/Code.gs`) แยกแท็บ ยังไม่ออก / ออกแล้ว (ผ่าน QC = ออก) · แสดงหมายเหตุ **C** และ **P** (P = "หมายเหตุสำหรับ Pick Orders") · วันที่ในหมายเหตุ เช่น `Nut.24.10` = วันสั่งของ → ของมา **วันถัดไป** · เลยกำหนดขึ้นแดง
- **3 เพิ่ม GTIN:** ถ่ายรูปป้าย → ใช้**เลขที่พิมพ์ใต้บาร์โค้ด** (ป้ายมีหลายบาร์โค้ด = ตัวบน) → จับคู่ SKU ใน BigSeller → คนกดยืนยัน · เริ่มที่ WARRIX กับ GRAND SPORT (EGO/หงสบาท ไว้ทีหลัง) · ตัวอย่าง SKU จริง: `WA-242PLACL30-V1-7L`, `010245-ดำแดง-L` (GRAND SPORT = รุ่น-สี-ไซซ์, บาร์โค้ดบน `0102451030003`)
- **4 เพิ่ม SKU:** แบบหน้าเพิ่ม SKU ของ BigSeller แต่ง่ายบนมือถือ กรอกจากรูปป้าย · รอภาพหน้าจอหน้าเพิ่ม SKU จริง
- **6 งานมอบหมาย:** = แผนย้ายสินค้าของ BigSeller (`/api/v1/inventory/movingPlan/pageList.json`) — ทำทีหลัง
- **7 ยุบกล่อง:** รวม 2 กล่อง (ชั้นวาง) ที่มีของครึ่งเดียวเป็นกล่องเดียว เลือกเก็บเลขกล่องไหนก็ได้ · 1 กล่องหลาย SKU ได้แต่**แบรนด์เดียว** · มีไกด์แนะนำให้รุ่นเดียวกันอยู่ด้วยกัน (ทำหรือไม่ก็ได้)
- **8 เช็กโซนหยิบ:** เดินเจอกล่องว่าง → สแกน QR ที่กล่อง → ไปข้อ 9 อัตโนมัติ · รอรูปป้าย QR จริง
- **9 Auto มอบหมาย:** หาของมาเติมจาก `C-` ก่อน → `K-` → `H-` (H- ต้อง**ยกทั้งกล่อง** ลงกล่องว่างกล่องเดียว) · เลือกคนรับงานจาก dropdown บัญชีย่อย BigSeller
- **10 รอสั่ง:** ของที่ไม่มีทั้ง C- K- H-
- **ชั้นวาง:** ปุ่มสร้างทีละหลายช่อง — ยังหา endpoint สร้างชั้นวางของ BigSeller ไม่เจอ (ให้เจ้าของสร้างชั้นทดสอบ 1 ช่องในเว็บ แล้วจับคำขอ)

## หลังบ้าน BigSeller ที่ยืนยันกับบัญชีจริงแล้ว
- ทุกคำขอต้องมี header `clientType: 1` · `code 2001` = ไม่ได้ล็อกอิน
- ค้น SKU: `POST(form) /api/v1/inventory/merchant/pageList.json` `searchType: 'skuName'` (ค่า `'sku'` ไม่กรอง)
- สต็อกแยกทุกชั้นวาง: `POST(form) /api/v1/inventory/wms/shelfZonePageList.json` `searchType:'sku', inquireType:2` → `{shelfName, zoneName, warehouseName, onhand, available}`
- ยอดต่อคลัง: `POST(form) /api/v1/inventory/scan/merchant/codeWithExtraInfo.json` → `onhand`, `available`
- โซน: `POST(json) /api/v1/warehouseZone/getWarehouseZoneList.json {warehouseId}` — คลัง "ออนไลน์" id 48660: เก็บ 5394, หยิบ 5395, จริง 1885940 · ชั้นวาง 3,266 ช่อง
- รายการชั้นวาง: `POST(form) /api/v1/inventory/shelf/pageList.json`
- ออเดอร์จากเลขพัสดุ: `GET /api/v1/order/v2/scanTrackingNo.json` · รายละเอียด/หมายเหตุ: `GET /api/v1/order/detail.json?id=`
- หน้าเว็บ BigSeller ที่เกี่ยว: `/web/inventory/shelf/index.htm`, `/web/inventory/warehouseInventory.htm`, `/web/inventory/movingGoods/index.htm`

## ยังไม่ได้ทำ / ยังไม่รู้
- BigSeller ยอมให้ล็อกอินจากเซิร์ฟเวอร์ต่างประเทศไหม (ทดสอบตอนเช่าเซิร์ฟเวอร์จริง)
- บันทึกแท็บ lock ใน Google Sheet แบบที่อะตอมมิคทำ
- ล็อกอินเก็บในหน่วยความจำ — รีสตาร์ตเซิร์ฟเวอร์ = ทุกคนต้องล็อกอินใหม่
