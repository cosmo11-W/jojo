# jojo — แอพมือถือของอะตอมมิค

อ่าน `../อะตอมมิค/CLAUDE.md` ก่อน เพราะบันทึกหลักทั้งหมดอยู่ในนั้น · ตอบผู้ใช้เป็นภาษาไทย

- `app\` เป็น HTML/CSS/JS ล้วน ไม่ต้อง build · อะตอมมิค (`../อะตอมมิค/โปรแกรม/jojo.js`) เป็นตัวเสิร์ฟหน้าแอพและตอบ API
  - ตอนเปิดแบบพัฒนา เสิร์ฟจากโฟลเดอร์นี้ตรง ๆ
  - ตอนติดตั้ง ถูกรวมเข้าตัวติดตั้งไปไว้ที่ `resources\jojo`
- โค้ดทั้งหมดอยู่ใน `app\app.js` · ใช้สีตามรูป jojo: เขียว `#1f5a3c` / ม่วง `#8a3fa8` / ทอง
- **แอพ jojo ตัวใหม่ (แบบ B, เริ่ม 24 ต.ค. 2026) อยู่ที่ `server\`** — แต่ละคนล็อกอินบัญชีย่อย BigSeller เอง ไม่ต้องพึ่งอะตอมมิค · อ่าน `server\README.md` ก่อน (สถานะทุกหน้า + สิ่งที่เจ้าของตอบไว้ + หลังบ้าน BigSeller ที่ยืนยันแล้ว) · ดีไซน์ธีม JoJo ม่วง–เหลือง: `design\jojo-manga-ui.html`
  - ถามเจ้าของก่อนออกแบบ/ทำฟังก์ชันใหม่ (เจ้าของไม่ชอบให้เดาเอง) · ทำทีละอย่าง ประหยัด token
  - ห้ามเปิด `JOJO_WRITE=1` ลองกับของจริงถ้าเจ้าของไม่ได้สั่ง
- ทดสอบโดยไม่แตะ BigSeller จริง: เปิดอะตอมมิคด้วย `ทดสอบ-ข้อมูลจำลอง.cmd` แล้วเปิด `http://127.0.0.1:5541` (ขนาดมือถือ)
